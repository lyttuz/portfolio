# Registro de decisões de arquitetura

Cada arquivo numerado aqui é um ADR (Architecture Decision Record): uma
decisão de arquitetura registrada no momento em que foi tomada, com o
contexto que a motivou e a consequência de segui-la.

Todo ADR segue o mesmo formato: Contexto, Decisão, Consequências e Como
falharia sem avisar. A última seção existe porque o que importa numa decisão
de arquitetura não é só o que ela resolve, é também o jeito silencioso pelo
qual ela pode deixar de valer sem que ninguém perceba.

Um PR que muda arquitetura cria ou atualiza um ADR aqui. O modelo de PR do
repositório pergunta isso.
